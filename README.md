# SoDi - Games for Kids

[SoDi](https://sodigames.com) is a set of simple web-based kids games for desktop or mobile browsers.

Currently have the following games:
1. Alien Shooter
2. Word Search
3. Tic-Tac-Toe
4. Memory Game
5. Drawing Game
6. Treasure Row
7. Chomp Chomp
8. Picture Difference Game

No login, no ads, easy to start. Enjoy!
